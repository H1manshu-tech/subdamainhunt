# 🌐 MrBlack 5-in-1 Parallel Subdomain Fusion Engine

An advanced, enterprise-grade reconnaissance framework built for cybersecurity researchers and bug bounty hunters. This script automates the orchestration of 5 industry-standard subdomain enumeration tools simultaneously, parsing their dynamic outputs into a single, deduplicated, clean target database.

Developed by **Himanshu** (Owner of **H-Secure Systems**).

---

## 🚀 Features & Core Capabilities

*   ⚡ **Parallel Multiprocessing Engine:** Spawns 5 independent background threads at the same time to reduce recon time by 80%.
*   🔑 **Bi-Attempt Security Lockout:** Protected by an interactive double-attempt authentication gateway with custom alert consoles.
*   🌈 **Hacker Aesthetic (Rainbow Interface):** Custom ANSI escape color matrices presenting an automated military-grade interface.
*   📊 **Smart JSON Parsing:** Native integration with `jq` to parse complex nested JSON schemas generated by engines like Knockpy.
*   🧹 **Workspace Sanitization:** Automatically scrubs individual raw output logs after compiling the unified master target list.

---

## 🛠️ Integrated Security Engines

The framework consolidates intelligence from the following 5 layers:
1.  **Subfinder** (Passive API harvesting)
2.  **Assetfinder** (SSL/TLS certificate transparency logs parser)
3.  **Sublist3r** (Search engine OSINT indexing crawler)
4.  **Amass** (Active/Passive DNS infrastructure tracker)
5.  **Knockpy** (API integration mapping network analyzer)
